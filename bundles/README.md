# Release bundles

[Repository overview](../README.md)

- [V3 bundle](jev_benchmark_v3_bundle.zip): the completed published notebook, frozen source, protocols, and original development tools.
- [V2 bundle](jev_benchmark_v2_bundle.zip): the historical V2 source and notebook release.

Both ZIPs retain their original bytes and internal filenames. Commands inside them refer to their original flat layout. The [V3 manifest](../published_results/manifest.json) records the published notebook and bundle hashes.

Fresh builds go into ignored `generated/` and use the current repository layout. These source bundles do not contain the full Kaggle result archive, dataset snapshots, or per-example predictions.
